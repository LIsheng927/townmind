TownMind 伙伴 Demo

这是个纯网页小工具，不是 Unity——只是为了能亲眼看到 agent 的决策过程， 不用装 Unity 也能玩。它直接连你本机跑起来的服务端，用的是真实的大模型（如果你配了 key）。 先在另一个终端启动服务端： cd server uv run uvicorn townmind.main:app --port 8000 方向键 / WASD 移动蓝色的"你"。伙伴是绿色的 Alice。 下面输入框可以对 Alice 说话，试试： "跟着我" "帮我把铁剑搬到广场" "帮我把剑搬到广场"（故意说得含糊，看她是不是会反问是哪把剑）
